|---|---|

## 구현 시 주의 [확정 — 이미 겪음]

- **모든 공공데이터포털 엔드포인트는 `https://`.** 평문 HTTP(80)는 2026-08-02
  무렵부터 응답하지 않는다. TCP 는 연결되고 응답만 안 와서 장애로 오인하기 쉽다.
- **인증키는 디코딩 키.** `urlencode` 가 자동으로 퍼센트 인코딩한다.
- **요청 속도를 편다.** 포털은 인증키 단위로 429 가 걸리고, STCIS 는 하루 총량에
  걸린다. 새 수집기는 `Pacer` 를 재사용한다.
- **읽기 타임아웃은 `URLError` 가 아니다.** `response.read()` 가 `socket.timeout`
  을 그대로 올린다. 재시도 루프는 `OSError` 로 받아야 한다.
